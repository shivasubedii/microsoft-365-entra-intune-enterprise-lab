# Interview Guide

## Tell me about this project
I built this project to demonstrate how Microsoft cloud services work together in a real IT administration workflow. I focused on employee onboarding and offboarding, Entra ID identity management, Microsoft 365 services, MFA, access controls, endpoint-management concepts, PowerShell automation and troubleshooting.

Instead of documenting only configuration steps, I included support incidents so I can demonstrate how I would diagnose problems before making changes.

## Example: User Cannot Access Outlook
I would first determine whether the problem is limited to the Outlook client or affects the user's Microsoft 365 account more broadly. I would verify account status, authentication, licensing, mailbox availability and web access. That helps isolate whether the root cause is identity, licensing, Exchange Online, permissions or the local client.

## Example: Offboarding
I would treat offboarding as more than disabling an account. I would verify the authorized request, block sign-in, revoke sessions, address credentials and group access, handle mailbox/data requirements, remove device access where applicable, review licensing and confirm the user can no longer access protected resources.

## Scope
When discussing the project, distinguish completed academic Microsoft 365 administration experience from documented Intune and expanded Conditional Access design scenarios. Do not describe a design scenario as production experience.
