# Portfolio Highlights

## 30-Second Project Summary
I designed and documented an enterprise-style Microsoft cloud administration environment focused on Microsoft 365, Entra ID, secure employee lifecycle management, endpoint governance and IT support troubleshooting.

The project connects identity, licensing, collaboration services, authentication, endpoint compliance and PowerShell administration rather than treating them as isolated technologies.

## What I Can Explain in an Interview
- How I would onboard a new employee from account creation through access verification.
- How I would securely offboard an employee and revoke existing sessions.
- How Entra ID groups can simplify access administration.
- How MFA and Conditional Access protect cloud resources.
- How to separate an Outlook problem from an identity, license or mailbox problem.
- How Intune compliance can interact with Conditional Access.
- Why least privilege and verification are important after administrative changes.
- How PowerShell can reduce repetitive administrative work.

## Strongest Demonstrations
1. Employee onboarding and offboarding workflows
2. Identity and group design
3. Seven structured troubleshooting incidents
4. Microsoft Graph PowerShell examples
5. Security-first access-control design
