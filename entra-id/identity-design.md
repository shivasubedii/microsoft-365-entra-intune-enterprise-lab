# Microsoft Entra ID Identity Design

## Example Groups
- SG-HR-Users
- SG-Finance-Users
- SG-Sales-Users
- SG-IT-Users
- SG-M365-Standard
- SG-SharePoint-HR
- SG-SharePoint-Finance

## User Lifecycle
Identity records should include consistent display name, username, department and job information. Access should be granted through role-appropriate groups rather than individually wherever practical.

## Administration Checklist
- Verify user identity details.
- Create or update account.
- Assign department/group membership.
- Assign required license.
- Configure authentication requirements.
- Validate access.
- Document changes.

## Least Privilege
Users receive only the access required for their role. Administrative roles remain separate from normal user access wherever practical.
