# Microsoft 365 Service Administration

## Exchange Online
Portfolio tasks include:
- User mailbox administration
- Mailbox permissions concepts
- License/service verification
- Troubleshooting user access and mail flow at a support level

- User/service access

## SharePoint
- Site access concepts
- Group-based authorization
- User access troubleshooting

## Troubleshooting Principle
Determine whether the issue is identity, license, service, client, permissions or policy related before changing configuration.
