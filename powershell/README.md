# PowerShell Administration

These scripts demonstrate repeatable reporting/administration patterns for Microsoft 365 and Entra ID.

## Safety
Review commands, required modules, tenant permissions and output before execution. Portfolio examples should be tested in a lab tenant rather than blindly executed in a production environment.

## Included
- `Get-M365UserReport.ps1` - exports a basic identity inventory.
- `Get-DisabledUsers.ps1` - identifies disabled identities.
