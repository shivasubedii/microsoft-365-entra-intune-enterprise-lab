# Scenario: Conditional Access Block
**Problem:** A valid user is denied access.

**Investigation:** Review sign-in details and the Conditional Access policies evaluated for the request. Check user, application, device and authentication requirements.

**Root Cause:** The sign-in does not satisfy an applicable access policy.

**Resolution:** Correct the underlying compliance/authentication condition or, if policy configuration is wrong, follow approved change control. Do not simply disable security.

**Verification:** Confirm the authorized sign-in satisfies the intended policy.
