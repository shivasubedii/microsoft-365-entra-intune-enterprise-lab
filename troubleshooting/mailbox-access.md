# Scenario: Outlook / Mailbox Access
**Problem:** A user cannot access their mailbox.

**Investigation:** Separate client problems from identity/service problems. Verify sign-in, license/service assignment, mailbox availability, web access and relevant permissions.

**Likely Root Cause:** Identity, licensing, client configuration or mailbox permission issue.

**Resolution:** Correct the identified layer rather than repeatedly reinstalling the client.

**Verification:** Test send/receive and expected mailbox access.
